# موقع MYGAMES 🎮

موقع إلكتروني ثابت (Static Website) بسيط وجاهز لعرض تطبيقات الألعاب الستة الخاصة بك من متجر Google Play.

## محتويات المشروع
```
game-site/
├── index.html      → الصفحة الرئيسية
├── css/style.css   → التنسيقات
├── js/script.js    → التفاعلات (القائمة، زر العودة للأعلى)
├── images/         → أيقونات الألعاب الستة
└── README.md       → هذا الملف
```

## كيف تنشر الموقع مجانًا؟

لديك عدة خيارات مجانية بالكامل، اختر الأسهل بالنسبة لك:

### 1) GitHub Pages (الأشهر والأكثر ثباتًا)
1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك.
2. أنشئ مستودعًا (Repository) جديدًا باسم مثل `my-games-site`.
3. ارفع جميع محتويات هذا المجلد إلى المستودع (يمكنك السحب والإفلات من واجهة GitHub مباشرة).
4. من إعدادات المستودع Settings → Pages، اختر الفرع `main` والمجلد `/root`، ثم احفظ.
5. بعد دقيقة أو دقيقتين سيصبح موقعك متاحًا على رابط شبيه بـ:
   `https://username.github.io/my-games-site/`

### 2) Netlify (الأسرع - بالسحب والإفلات)
1. ادخل إلى [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد `game-site` بالكامل وأفلته في الصفحة.
3. سيُنشر موقعك فورًا برابط مجاني مثل `https://your-site.netlify.app`.
4. يمكنك لاحقًا ربط نطاق مخصص مجانًا من إعدادات Netlify.

### 3) Vercel
1. أنشئ حسابًا على [vercel.com](https://vercel.com)
2. اختر "Add New Project" وارفع المجلد أو اربطه بمستودع GitHub.
3. اضغط Deploy وسيكون موقعك جاهزًا خلال ثوانٍ.

### 4) Cloudflare Pages
1. أنشئ حسابًا على [pages.cloudflare.com](https://pages.cloudflare.com)
2. ارفع المجلد مباشرة أو اربطه بمستودع Git.
3. النشر مجاني بالكامل مع دعم CDN عالمي سريع.

## تخصيص الموقع

- **لإضافة لعبة جديدة**: انسخ أحد عناصر `<article class="game-card">...</article>` في ملف `index.html`، وغيّر الاسم والوصف ورابط Google Play وأيقونة الصورة.
- **لتغيير الألوان**: عدّل المتغيرات في أعلى ملف `css/style.css` داخل `:root { ... }`.
- **البريد الإلكتروني**: غيّر `info@mygames-studio.com` في قسم "تواصل معنا" إلى بريدك الفعلي.

## ملاحظة
الموقع مبني بـ HTML/CSS/JavaScript فقط (بدون أي إطار عمل)، لذا يعمل على أي استضافة ثابتة مجانية بدون الحاجة لخادم خلفي (Backend) أو قاعدة بيانات.
